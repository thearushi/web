🛡️ About VigilSec Web Scanner

VigilSec is an educational, non-intrusive security baseline auditor designed to analyze web infrastructure configurations, modern defensive HTTP response headers, cookie flags, and transport encryption.

OWASP Defensive Header Guidelines:
  • HSTS: Enforces HTTPS browser caching and defeats SSL stripping.
  • CSP: Defeats Cross-Site Scripting (XSS) and malicious data injections.
  • X-Content-Type-Options: Prevents MIME-type sniffing attacks.
  • X-Frame-Options: Mitigates Clickjacking by controlling framing.
  • Referrer-Policy: Protects user URL metadata in cross-site links.
  • Permissions-Policy: Disables sensitive hardware APIs.

* Passive scanner only. Always obtain authorized permission before auditing external domains.
